千呼万唤始出来。

今天凌晨，OpenAI 官方宣布，适用于 Linux 的 ChatGPT 桌面应用正式进入预览阶段。

*[图片]*

在开发者的世界里，Linux 的重要性无需多言。绝大多数服务器跑在 Linux 上，云原生、后端、AI 训练与部署的日常，也大都发生在这套系统里。

但是 OpenAI 的原生 AI 能力在 Linux 系统中长期缺位 —— 桌面客户端始终没有覆盖。

在这次预览版发布后，用户可以在受支持的 Linux 系统上，直接使用 ChatGPT、ChatGPT Work 和 Codex 三件套，在自己原本就熟悉的工作和开发环境里，处理项目与浏览器工作流程。

需要注意的是，Linux 的发行版本非常繁杂，ChatGPT 桌面端仅适用于以下 Linux 发行版：

- Ubuntu 24.04 LTS 和 26.04 LTS
- Debian 13
- Fedora 43 和 44

用户可以前往 Codex 下载页面使用 .deb 或 .rpm 软件包安装 x64 或 ARM64 版本。

虽说兼容性有限，但至少是一个好的开始。

Linux 用户终于等到了

评论区全是 Linux 用户的欢呼声。

*[图片]*

早在 2024 年，OpenAI 官方社区就出现过一则「请求 Linux 桌面应用」的帖子，许多人响应。直到几天前，还有人发文称「自己专门注册论坛账号，就是为了顶这个帖子」。

*[图片]*

一位网友甚至直接在 Omarchy 上跑起了 ChatGPT 桌面端。Omarchy 并不在 OpenAI 目前公布的官方支持名单里，他的解决办法是直接让 Codex 帮忙适配和安装.deb 包。

他还提到，现阶段 Linux 上的 Computer Use 似乎仍主要集中在 Chrome 等浏览器自动化，和 macOS 相比，对整个桌面环境的控制能力还有差距。
