什么是组队学习

组队学习活动，于2018年8月2日由Datawhale发起，已经坚持组织了八年。

初衷很简单，就是一群志同道合的小伙伴，一起学习讨论，一起克服拖延，一起组队打Boss。没有老师，没有教学，有的是一群热爱学习、渴望改变的人，大家交流学习，互促共进。

一、LLM 专题

1. 开源教程：jev cookbook（从零入门 Jev）

**课程简介本次共学围绕 JEV Cookbook** 展开，第一期以 **JEV 基础认知、核心原语、Cookbook 实战与基础评测** 为主。课程不追求一次性覆盖全部进阶内容，而是帮助大家先建立对 JEV 的基本理解，掌握 Choice / Score / Noul 三种核心问题原语，并通过真实案例理解 JEV 在分类、排序、路由、判断等任务中的使用方式。

**学习形式以：教程阅读 + Notebook 实验 + 简单改造 + 学习总结**为主。第一期暂不重点展开 Agent 深度集成、Laya、本地模型、RLCD 微调等进阶内容，降低第一次学习门槛，优先保证大家能够跑通、理解并实际使用 JEV。

**适合人群：适合有一定 Python 基础，对 JEV、System One Model 感兴趣，希望通过实战探索分类、路由、Tool Selection 等任务在 LLM / Agent / RAG 应用中如何实现的同学。**

学习名额：360人

开源内容

[https://github.com/datawhalechina/jev-cookbook](https://github.com/datawhalechina/jev-cookbook)

二、Agent 专题

5. 书籍：DeepSeek harness 技术入门

**课程简介基于DeepSeek Harness开源项目学习Agent（智能体）软件的系统化组织方式，参考书籍《Deepseek Harnesss技术入门与架构原理》。本次组队学习前三章内容，全书从“模型只会生成Token，Agent要完成任务”这一根本矛盾切入，根据“一切皆插件”（Everything Is a Plugin）原则，剖析DSH如何把模型适配、工具注册、会话记录、Agent循环等能力组织进统一的插件组合体系，并借助Cordis运行时实现插件的动态挂载、生命周期管理与依赖重新解析。适合人群：适合有一定大模型应用经验的开发者、AI 应用工程师与架构师阅读，也适合所有想理解“Agent 软件应当如何组织”这一问题的技术读者参考。学习名额：360人开源内容https://www.datawhale.cn/learn/summary/381**
