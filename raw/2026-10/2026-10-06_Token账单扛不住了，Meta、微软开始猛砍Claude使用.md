情况似乎不太妙。

就在 Anthropic 冲刺 IPO 的关键节点，几家重要客户开始同时收紧 Claude 的使用。

据 The Information 报道，Meta 和微软都在减少员工对 Claude 的依赖，并推动开发者更多转向自家的 AI 工具和模型。

其中，Meta 此前曾使用 Claude Code 开发 Muse，但在 Muse 上线后，Claude Code 的活跃用户数从 6 万降至 3 万，减少 50%，并开始用自家的 Muse Code 取而代之。

微软已经将内部 Claude 支出削减超过 33%，把单个员工每月的 Token 预算从 10 万美元直接砍到 1 万美元，同时让 Copilot 自动把请求路由到更便宜的模型。

Meta 内部，Claude Code 用户直接腰斩

Meta 内部 Claude Code 用户直接腰斩，其中一部分原因来自今年春季的裁员。当时 Meta 从约 7.8 万名员工中裁去了大约 10%。

*[图片]*

但报道称，更重要的原因在于，Meta 正在主动把员工从 Claude Code 引导到自家的 AI 编程工具上。

Meta 已经建立了自己的 AI 编程产品体系。

其中 Muse Code，使用 Meta 自家的模型，被定位为 Claude Code 的竞争产品。今年 8 月，Meta 已经开始向外部客户测试 Muse Code。根据 The Information 获得的内部数据，这款产品最近在 Meta 内部拥有超过 6000 名员工用户。

另一款仅供内部使用的 AI 编程工具 MetaCode，用户数则已经超过 3 万人。

换句话说，当 Claude Code 的内部用户从 6 万降到 3 万时，Meta 自己的 AI Coding 工具正在迅速补位。

这背后还有一个更加现实的问题：钱。

今年 6 月的一份 Meta 内部备忘录显示，公司今年仅内部使用 AI 工具的支出，就曾朝着数十亿美元规模发展。

Claude Code 当时又是 Meta 最流行的第三方编程工具。The Information 获得的数据显示，在最近一个 28 天周期内，Meta 在 Claude Code 上的花费就超过了 1.05 亿美元。

按照这个速度持续下去，其成本规模可想而知。

微软一年 10 亿美元的 Claude 账单，也开始砍了

今年早些时候，微软员工使用 Claude 的规模迅速增长。

截至今年 5 月，公司内部预计，包括 Claude Code、Copilot 中的 Claude 模型以及用于网络安全扫描的 Anthropic 模型在内，员工使用 Anthropic 技术产生的年化开支已经朝着至少 10 亿美元发展。

随后，微软将这一预算水平削减了超过三分之一。

一方面是控制 AI 成本，另一方面，则是希望员工更多使用微软自己的产品。

微软开始减少 Claude Code 订阅，并要求员工尽量通过 GitHub Copilot 使用 Claude。

GitHub Copilot 本身允许开发者选择不同模型，但其自动模式在多数情况下会优先路由到 OpenAI 模型。对于微软来说，这里面还有一层特殊的经济账。由于微软与 OpenAI 之间的商业合作关系，将更多内部工作负载转向 OpenAI 模型，能够降低微软实际需要支付的模型成本。

微软开发者工具负责人 Jay Parikh 在今年 8 月的一份内部备忘录中也提到，各部门本财年都开始管理自己的 Token 预算，需要不断优化模型使用方式。

微软、Meta 都在砍 Claude，但 Anthropic 说影响很小

Anthropic 给投资者传递的信息是：自今年 1 月以来，Anthropic 的年度经常性收入（ARR）已经增长了约 7 倍，从约 90 亿美元增至 650 亿美元。

目前，大约有 6000 家企业客户每年在 Claude 上的支出超过 10 万美元，这一数字较去年增长了 4 倍；同时，已经有超过 100 家大型企业客户每年在 Claude 上的支出超过 1000 万美元。

*[图片]*

来源：[https://x.com/ns123abc/status/2107229918467588427](https://x.com/ns123abc/status/2107229918467588427)

微软确实将员工内部使用 Claude 的支出削减了大约 33%，但目前每年仍向 Anthropic 支付约 6.7 亿美元。与此同时，微软 Copilot 面向外部客户的 Claude 使用量还在继续增长。

Meta 也确实将内部 Claude Code 用户数削减了 50%，但目前每个月仍向 Anthropic 支付大约 1.05 亿美元。

至于两个客户贡献了 Anthropic 25% 营收这一说法，那是 2025 年的数据。当时 Anthropic 的全年营收只有 46 亿美元，这两个客户合计贡献约 11 亿美元。

而放到今天，这 11 亿美元只占 Anthropic 当前年化业务规模的不到 2%。
