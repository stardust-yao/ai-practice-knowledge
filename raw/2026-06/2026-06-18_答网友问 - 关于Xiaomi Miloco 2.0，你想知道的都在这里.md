今天，小米正式发布以 MiMo 大模型为核心的全屋智能 AI 开源方案——Miloco 2.0。

相比 Miloco 1.0，Miloco 2.0 在下一代智能家居的探索上“更进一步”：让家里的设备不再只是“听指令”，而是开始“会思考”，更深度的探索全新智能家居形态。

它能看见家里发生了什么，也能听懂你的需求；不仅会执行命令，还能记住家人的习惯、主动跟进长期任务，并在需要时提醒和干预。

Miloco 2.0 现以 Agent 形式接入 OpenClaw，支持一键安装和部署，支持 macOS、Linux、Windows 系统，后续计划会陆续适配 Claw 类产品。

为了让更多人理解 Miloco 2.0 到底能做什么、怎么用，我们写了这篇科普。

**01**

Miloco 2.0 是什么？有什么能力？

Miloco 2.0 是一个面向未来的全屋智能 AI 开源方案。如果要用一句话概括，它更像是一位真正住在家里的 AI 智能管家。

- 摄像头是它的眼睛，能看见谁在家、在做什么；
- 麦克风是它的耳朵，能听到孩子哭、老人呼唤；
- 米家设备是它的手脚，开灯、关空调、拉窗帘……全都能控制；
- Miloco 则负责理解、记忆和决策，让全屋设备协同工作。

支撑 Miloco 2.0 从规则控制迈向“主动智能”的，是背后两大核心能力的进化：

## ▍第一，接得住"长期任务"，不是一次性指令

过去的智能家居只能完成 “一句话对应一个动作”：开空调、关灯、拉窗帘。但生活中的很多需求，不是一次动作就能解决的。比如：

- “帮我留意孩子的坐姿”
- “孩子连续看电视满1小时就自动关掉”
- “如果老人夜里长时间没回房间，提醒我”

这类任务需要持续观察、记录状态、判断条件，再决定什么时候提醒或干预。Miloco 2.0 可以把这些长期目标变成持续跟进的家庭任务：

- “帮我留意孩子的坐姿”——它会在孩子驼背时自动提醒
- “孩子看电视满1小时就关掉”——自动计时，不用你盯着

## ▍第二，有常识、有记忆，会主动关心你

Miloco 2.0 不仅能看见、能理解，还能主动提供服务。

- 检测到孩子哭了、老人可能摔倒、燃气灶一直开着……它能自动判断风险等级，及时通知你
- 悄悄记住你的习惯：比如每天晚上 8 点回家，它就自动打开暖光灯、播放你喜欢的音乐

这些习惯会逐渐沉淀成专属的家庭档案，帮你一键生成个性化自动化任务。

**02**

从 1.0 到 2.0，Miloco 的升级有哪些？

去年11月，小米发布了全屋智能探索方案 Miloco 1.0，开始尝试用大模型重新定义智能家居。

有了 Miloco 1.0，你不再需要研究繁琐的手动设置，只需要像和人聊天一样说出需求，大模型就能自动理解你的意图，并帮你完成配置。

但是，Miloco 1.0 主要靠规则驱动——你需要提前把每一条规则都设好。而现实生活千变万化，规则永远写不完。

这次发布的 Miloco2.0，在智能家居的未来形态探索上更进一步。它基于小米自研 MiMo 大模型，并通过 Agent 与 OpenClaw 连接，带来了全新的四大升级：

*[图片]*

多模态感知：看到灶台水沸、听到蜂鸣，自动提醒关火

主动智能：看到家庭成员回家偏晚，主动送上加班关怀

家庭记忆：根据家庭成员不同喜好，自动调整环境光线

持续任务：策划生日惊喜，等妻子回家后立即执行

现在，安装上 Miloco 2.0 后，家里的设备将第一次真正学会“看得见、听得懂、记得住、会思考、能行动”。 智能家居正从“执行指令的通用智能助手”，进化为“主动服务的个性化 AI 管家”。

**03**

如何部署使用 Miloco 2.0？使用成本如何？

一点都不难，甚至可以让 AI 帮你装。你只需要：

- 一台能跑 OpenClaw 的电脑（Mac / Windows / Linux 都行）；
- 一个小米账号（绑定家里的米家设备）；
- 一台米家摄像头（已有的就行）；
- 一个多模态大模型的 API Key。

然后给 OpenClaw 发送指令 ：

> “帮我安装 Miloco 插件：https://github.com/XiaoMi/xiaomi-miloco”

它会帮你自动完成环境准备、绑定账号和模型，全程几乎不用动手。

详细步骤可参考《Miloco 2.0 使用说明书》**：**

[https://github.com/XiaoMi/xiaomi-miloco/blob/main/user_guide_zh.md](https://github.com/XiaoMi/xiaomi-miloco/blob/main/user_guide_zh.md)

使用成本高吗？Miloco 2.0 本身完全开源免费（仅限非商用），摄像头和米家设备，优先利用家里已有设备即可，无需额外购买。真正的成本主要来自两部分：

- 一台运行 OpenClaw 的设备（家里的旧电脑也行）
- 大模型 API 调用费用

如果使用 Xiaomi MiMo 模型，Miloco 2.0 开源首周还有免费送 Token 的活动，点击阅读原文跳转链接**即可参与。**

**04**

Miloco 2.0 如何认人、记事，做到“越用越懂这个家”？

怎么认人？Miloco 会综合人脸、身形等多种信息，判断“眼前这个人是谁”。你只需要给家人传几张照片或一段视频，它就能记住“这是谁”。以后摄像头看到这个人，就能叫出名字。如果暂时没认出来，也不用担心。系统会先把对方放进“陌生人池”，等你确认后再完成登记。

怎么记事？Miloco 2.0 最大的特点，是首次把“家”作为记忆主体。它记住的，不只是某个人，而是整个家庭。它既能记住每位家庭成员的偏好、作息和习惯，它也会每天凌晨默默整理观察到的规律，反复出现的变成长期档案。

有了“身份识别 + 家庭记忆”，同一句话、同一个场景，对不同家庭成员，它都能给出不同反应。用得越久，它越懂这个家。

**05**

如何把“规则”升级成“会自己跟进的任务”？

传统智能家居最擅长做的，是规则。比如：

- “温度超过 28℃，打开空调。”
- “晚上 7 点，打开客厅灯。”

但规则只适合处理简单、明确的条件。对于那些模糊、长期、需要持续跟进的目标，它往往无能为力。比如：

- “监督孩子每天看电视别超过 1 小时。”
- “提醒我保持良好坐姿。”
- “帮我关注老人夜间活动是否异常。”

现在，Miloco 2.0 能把这些目标升级成真正的“家庭任务”。它会持续观察、累计进度、适时提醒，并在必要时主动干预。

这得益于Miloco 2.0 基于自研 MiMo 大模型构建，具备了三项核心能力：

- 规则：从瞬时触发升级到全周期持续跟踪，任务开始、进行中、结束时不同响应
- 调度：从单次执行升级到灵活时间编排，支持定时、周期、延迟等多种触发方式，驱动定时汇总、周期提醒等任务自动运行。
- 状态：从无记忆升级到持久化存档，支撑持续任务的追踪

如果把 Miloco 2.0 是一位 AI 智能管家，那么这三项能力就像它的“待办清单、日程表和工作日志”。三者协同，才让它不只是执行指令，而是真正能够长期跟进、主动完成家庭任务。

**06**

Miloco 2.0 是如何保证用户隐私安全的？

Miloco 2.0 的核心原则只有一句话：原始画面“用完即弃”，数据本地保存，可清空。

**原始画面不出本地：**摄像头采集的数据与 OpenClaw 完全隔离。AI 只能获取“发生了什么”的语义结果，而无法访问原始视频画面。

**数据完全由用户掌控：**所有数据默认只保存在本地。云端不留存。端侧日志 30 天自动清理。你还能给摄像头设黑名单、给家庭设白名单，想关哪个关哪个。

**-**

目前，Miloco 2.0在面对更复杂、多变的真实家庭环境，仍无法做到每次都准确完成，未来还将持续优化和提升。

但 Miloco 2.0 已经让我们看到一种全新的生活方式：未来的智能家居，不再只是执行命令，而是真正理解生活。

Miloco 团队正在持续优化，希望把它打造成一个会理解你、记得你、主动帮你的家庭 AI 管家。
